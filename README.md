## 앱 내 업데이트

이미 게시된 관리기60 테스트 업데이트 ZIP과 서명된 목록은 그대로 유지합니다. 이번 설치 파일 공개로 테스트·안정 업데이트 채널이나 자동 업데이트 대상이 바뀌지는 않습니다. 기존 릴리스의 프리릴리스 상태도 유지합니다.

업데이트는 서명된 목록과 파일 무결성, Developer ID 서명 및 macOS 공증을 확인합니다. 확인 버튼만으로 앱을 교체하지 않으며 설치는 사용자가 선택할 때 진행합니다.
